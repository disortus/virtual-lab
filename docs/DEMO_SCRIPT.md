# Сценарий живой демонстрации (ITFest 2026, Phase 2)

## 1. Обзор и каталог (30 сек)
1. Откройте главную страницу (`/`): слоган **«Don't just learn science. Discover it.»**, единый акцент `#315BE8`, цикл исследования.
2. Откройте `/labs` (`Chemistry Lab — Coming Soon`), затем перейдите в `/labs/physics` — покажите 5 направлений физики и 8 уникальных интерактивных установок.

## 2. Guided Research — Закон Ома или Идеальный газ (90 сек)
1. Откройте `EXP—01 Закон Ома` (по умолчанию запускается **Guided Research**).
2. Покажите точный ручной ввод числа в поле рядом со слайдером, переключение лабораторного ключа и тепловую визуализацию мощности резистора.
3. Пройдите этапы `01 Изучение → 02 Гипотеза → 03 Эксперимент (2 замера) → 04 Наблюдение → 05 Анализ с AI → 06 Вывод → Научный отчёт`.
4. На странице отчёта покажите человекочитаемые параметры, таблицу замеров и кнопку **«Печать / Сохранить PDF»**.

## 3. Новые симуляции Phase 2 (90 сек)
1. **`EXP—05` Последовательное и параллельное соединение**: переключите схему прямо на стенде — токи ветвей и общее сопротивление мгновенно пересчитываются.
2. **`EXP—06` Второй закон Ньютона**: задайте `F_тяги <= F_тр`, чтобы показать порог трения покоя, затем увеличьте тягу и запустите разгон тележки с векторами сил.
3. **`EXP—07` Идеальный газ**: измените объём поршня и температуру на Canvas-установке — манометр, плотность соударений и изотерма обновляются в реальном времени.
4. **`EXP—08` Интерференция волн**: переключите фазовый сдвиг `Δφ` с `0°` (усиление) на `180°` (полное гашение) и нажмите **«Объяснить происходящее»**.
